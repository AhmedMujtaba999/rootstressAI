# Project Summary

## Project Name

AgriZone AI — Farm Image Zone Planner

## One-Line Description

An AWS Bedrock-powered multimodal AI system that analyzes farm images and provides practical zone division recommendations for agriculture.

## Problem

Farmers and agricultural planners often need to divide land into usable sections for irrigation, crop planning, soil treatment, and field management. Manually planning these zones can be time-consuming and inconsistent.

## Solution

This project allows a user to upload a field image and provide a text instruction. The backend sends both the image and prompt to Amazon Bedrock Nova Pro, which analyzes the image and returns a practical zoning recommendation.
